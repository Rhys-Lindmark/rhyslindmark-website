Message Hermes

Rhys’s private Poppy agent runs on his DigitalOcean Docker host.

Open private Hermes chat

On the Mac with the configured Hermes SSH connection, run npm run ask -- --copy-access-key from the Poppy source directory. Paste the key into the private chat to connect.

Use Hermes with Siri

  1. Create a shortcut named Ask Hermes. Add Dictate Text.
  2. Add Get Contents of URL for https://143.198.66.36/message. Choose POST and set the JSON field message to Dictated Text.
  3. Set the Authorization header to Bearer YOUR_ACCESS_KEY. Keep this shortcut private.
  4. Get run_url from the response with Get Dictionary Value and pass it to Open URLs. Sign in to see the reply as Hermes works.

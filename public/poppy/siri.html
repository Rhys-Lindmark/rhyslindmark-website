Ask Poppy with Siri

Set up a shortcut once, then say “Siri, Ask Poppy” and dictate your message.

Create the shortcut

  1. In Shortcuts on your iPhone, create a shortcut named Ask Poppy.
  2. Add Dictate Text.
  3. Add Get Contents of URL for https://ai.rhyslindmark.com/poppy/api/message. Choose POST and set the request body to JSON. Add a text field named message and set its value to Dictated Text.
  4. Add Get Dictionary Value to get reply from Contents of URL.
  5. Add Speak Text and use the dictionary value as its input.

Try “Find me a reading edition” or “How much does it cost?”

Open an edition for approval

To continue in Safari, get review_url from Contents of URL and pass it to Open URLs when the value exists. The browser asks you to approve the download.

A game about asking Jev the right questions

Night Shift at Hotel Null

You’re the hotel’s code. Jev is the concierge: it answers small, typed questions about each guest message in a blink. You choose what to ask and write the rules. Then the night begins.

1 · Read the rulebook

It’s the hotel’s policy. Jev never sees it. Only your code does.

2 · Pick question cards

Each one is a question Jev will answer for every guest. Some are traps.

3 · Write your code

If/then rules over Jev’s answers and what the hotel already knows.

4 · Run the night

Right call +100, wrong call −150, waking the manager −40.

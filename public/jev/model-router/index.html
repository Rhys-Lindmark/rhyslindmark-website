Model Router

Anti-pattern

Choice as a decision: “Which model should I use?”

Why this is worse

  • Jev makes the decision. Cost, speed and quality trade-offs are policy, and they live inside the model instead of in code you can read and test.
  • The options are just labels. “Claude Opus” describes nothing Jev can match against the prompt, so the answer depends on what Jev happens to know about each model.
  • It fails the human test. A smart person shown only this prompt would ask, “what do you care about, cost or quality?”
  • There’s nothing to change but the wording. No reasoning level, no thresholds, no rules to read. Changing policy means rewriting the question.

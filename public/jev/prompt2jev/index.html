Your prompt

Paste the LLM prompt you already have. Jev first judges whether it should become Jev at all. If it should, a cheap open-weight model (DeepSeek V4.1 Flash) drafts the questions, a truth table and decide(), and Jev lints every question. Flagged questions get one revision. Takes about a minute.

What it checks

  1. Is it a judgment? Jev answers questions with probabilities. It doesn’t write emails or copy values out of an invoice. Those prompts should stay on an LLM.
  2. Is the decision in code? The model writes the policy as a truth table and decide(). It asks Jev only for what needs reading.
  3. Does every question pass jev-lint? Each question is checked for being a decision, compound, hidden rules or math, the same four Nouls as jev-lint.

The drafts are a starting point. Check the policy in decide() against what your product actually does before you ship it. There’s also a command-line version: node run.mjs my-prompt.txt in takehome/ideas/prompt2jev.

A 1-bit system window on rose paper. Square, ink-ruled windows with black title bars sit on a near-white page, a single dusty rose marks whole sections, and terminal-mono labels tag everything like a spec sheet.

It feels like a research instrument from a 1984 desktop: precise, a little dry, confident enough not to decorate. Headlines are tight, capitalized grotesk; body copy is plain and readable. Every surface is a window or a rule. Nothing is rounded, nothing glows, nothing floats.

Guidelines

Do
  • Keep corners square: windows, buttons, inputs, chips, bars.
  • Draw structure with 1px Ink rules.
  • Use Rose for a whole field: a band, a hero, a section.
  • Label in mono, like a spec sheet.
  • Set display type tight (0.8) and capitalized.
  • Use Signal green only for pass, live and positive numbers.
Don’t
  • Round anything, or use pills.
  • Blur shadows or stack them; elevation is the 3px hard offset.
  • Use gradients, glows, orbs or colour washes.
  • Put Rose behind small UI or use it for text.
  • Add a second brand colour.
  • Use pure black; Ink is #1e1e1e.

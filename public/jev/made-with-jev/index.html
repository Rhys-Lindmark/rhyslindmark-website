        How a post gets in

        The feedback corpus holds every X post about Jev since the Sept 15 launch. Jev 1.14 answered a set of questions about each one. A post shows here when Jev says yes (0.70 or more) to both “Is this about Jev?” and “Does the author build with Jev?”. The use cases and builder types are more questions of the same kind. Grok’s replies are left out.

        By default each builder gets one card, their newest post. “Every post” shows all of them. Names, pictures and media come from X when the page loads; a post that has since been deleted keeps the text the corpus saved.

        Compare madewithjev.com/newest, which says “Updated Nov 13” but whose newest build page is from Oct 15.

# Claim Check operations

- Route: https://ai.rhyslindmark.com/jev/model-router (the /jev hub links to it)
- The page shows the Model Router (`demo: "route"`: one Score, four Nouls, Router v2's four extra Nouls and the anti-pattern Choice in a single call; prompt up to 1,000 characters), plus an Eval card read from `public/jev/eval-summary.json` (from `evals/model-router`). Since 2026-11-20 the page no longer shows Claim Check or Rock, Paper, Scissors; `/api/jev` still accepts both (`demo: "rps"`, or a claim and evidence). All demos share `/api/jev`, the Turnstile widget key and action, and every limit below.
- A visitor passes Turnstile once (verified server-side with action `jev_check` and hostname `ai.rhyslindmark.com`). The server then sets `jev_human`, an HttpOnly, Secure, SameSite=Strict cookie scoped to `/api/jev` that lasts 7 days, signed with HMAC-SHA-256 under a key derived from `JEV_KEY_SECRET`. Calls with a valid cookie skip Turnstile; without one, the API returns 403 with `needs_human: true` and the page shows the widget again. The owner asked for this on 2026-11-20. Rotating `JEV_KEY_SECRET` invalidates every cookie. There is no service-key or header bypass.
- Turnstile reduces automation; no CAPTCHA guarantees a visitor is human.
- Model pinned to `jev-1.14.0`. Published price checked 2026-10-27: $0.042 per million input tokens; output free; normal request context <=65,536 tokens. Source: https://docs.typesafe.ai/models
- Atomically reserve $0.01 before each API attempt, including upstream failures/timeouts; never refund. Lifetime reserve ceiling $20 (2,000 attempts), no automatic reset. At the documented context and price, those attempts cost at most about $5.51 in total. The headroom is intentional. Other applications using the same TypeSafe account are outside this cap.
- No hourly or daily caps. On 2026-11-20 the owner removed the old 10-per-IP-per-hour and 100-site-wide-per-day limits so Rock, Paper, Scissors can be played freely. The lifetime allowance above is the only usage limit; old rate counters in `jev_limits` are pruned as they expire.
- Limits and enabled state live in `jev_budget` and `jev_limits` in the private SQLite Durable Object `jev-ledger/JevLedger`, named `claim-check-production`, bound as `JEV_STATE`. Redeploys do not reset them. Missing database/configuration or failed verification stops before Jev.
- Immediate kill switch: set `JEV_ENABLED="0"` in `wrangler.toml` and redeploy. The private ledger also has an `enabled` column for administrative suspension. Do not reset/increase the allowance without user authorization.
- Usage: `SELECT reserved_micros/1000000.0 AS allowance_used_usd, enabled FROM jev_budget WHERE id=1;` This is a conservative allowance, not an exact TypeSafe invoice.
- Server key source: encrypted `jev_credentials` row, or an existing `JEV_API_KEY` runtime secret. Database ciphertext uses AES-256-GCM with a purpose-specific key derived from the existing runtime secret `JEV_KEY_SECRET`; preserve this secret or re-provision when rotating it.
- One-time owner provisioning is disabled unless production `JEV_SETUP_KEY_SHA256` matches SHA-256 of the exact owner-approved API key. It accepts only that key, writes ciphertext once with INSERT OR IGNORE, and cannot overwrite credentials. Remove that setup variable after provisioning. Never send key material to logs, source, or browser assets.
- Tests: `node --test functions/api/jev.test.mjs functions/api/jev-access.test.mjs functions/api/jev-database.test.mjs`. Tests use SQLite and real Web Crypto; CAPTCHA responses are mocked for security-path tests. Production validation still needs a user to complete the actual widget.

The private ledger Worker source is `jev-ledger.worker.js`, deployed using the Cloudflare API with a v1 SQLite migration. Public workers.dev and preview URLs are disabled. Do not delete, rename, or recreate its namespace (2e19bc441e7f499ab6f64d05aaed655a) or change its fixed object name: doing so would reset the lifetime allowance. The legacy D1 rows remain preserved but are no longer read by Claim Check.
